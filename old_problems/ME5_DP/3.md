# ME 5: DP

Bob is playing an online RPG. There are 3 good zones for grinding, and Bob starts in zone 0. Bob's automatic grinding script receives an array of monsters that are expected to appear, with each element of the array being of this struct:

```c
typedef struct {
    int zone; // 0, 1, or 2
    int xp;   // the value of defeating the monster, from 0 to 1000
} Spawn; // up to 1,000,000 spawns. At least 1.
```

For each monster, if Bob is in the same Zone, Bob can defeat it. Bob may also choose to change zones, but if he does so, he forgoes the opportunity to defeat the monster (the next monster will be the one he has an opportunity for). I.e., if Bob is in 0, and the first two monsters are in 0, Bob may defeat them. Then, if the third monster is in zone 2, Bob cannot defeat it. However, instead of defeating the second monster, he could have used that time to move to Zone 2, and he would be there in time for the second monster.

Your goal is to write a C function to compute the maximum sum of xp values that Bob can achieve. Your solution must run in $O(s)$, where $s$ is the number of spawns in the array. You may only use functions you define yourself. I recommend defining `max`.

```c
int max_xp(Spawn spawns[], int n_spawns);
```

Hint: set up your DP like this: for each time step, what is the highest value you could get if you were in zone 0, zone 1, and zone 2. Then, you can look at the previous step to determine if moving is worth it. The 4 possibilities are: we stayed in the zone and now kill the monster, we moved to the zone so we could kill the monster, we stayed in other zone z and ignored the monster, and we stayed in other zone z' and ignored the monster.

Hint 2: If you know that a monster is in zone z, then (z + 1) % 3 and (z + 2) % 3 are the other two zones.
