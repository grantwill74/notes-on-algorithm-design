# ME1: Proofs

1. (25%) Write a function in C:

```c
#include <stddef.h>

// Returns base^exp (base multiplied by itself exp times).
size_t ipow(size_t base, size_t exp);
```

Your implementation should do fewer than `exp` multiplications whenever possible (meaning, a correct answer will *not* be linear time). (-15 pts for a linear time solution)

Examples:
```c
ipow(2, 0) == 1;
ipow(2, 5) == 32;    // 2 * 2 * 2 * 2 * 2
ipow(3, 3) == 27;    // 3 * 3 * 3
ipow(5, 1) == 5;
ipow(7, 2) == 49;
```

2. (25%) Prove that your ipow is correct:
    - If you wrote an iterative version, state a precise loop invariant (15 pts) and show it’s maintained (10 pts).
    - If you wrote a recursive version, handle your base case(s) in full (10 pts) and prove the inductive step (15 pts). Use strong induction.

3. (25%) Determine its tight big-$O$ running time under the RAM model. Hint: it will be $o(\mathrm{exp})$ if you did it correctly.

4. (25%) Prove that it has that $O$-running time:
    - Iterative: count how many loop‐iterations or bit‐tests you perform (15 pts) and determine the correct bound for any loop body (10 pts).
    - Recursive: write down its recurrence (10 pts) and solve it—either by unfolding or an inductive proof (15 pts). Feel free to use the master theorem if you want.
