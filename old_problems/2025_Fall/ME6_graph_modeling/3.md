# ME 6: Graph modelling

Bob is the captain of a Spaceship. The map of visitable systems is a graph of nodes that look like this:
```c
typedef struct {
    int n_pirates;
    double x, y; // coordinates. ignore z: the galaxy is pretty flat
    int n_adjacent_systems;
    int* adjacent_systems;
} System;
System systems[10000]; // all known systems
```

Bob has 100 hull points, and every individual pirate he encounters will deplete one, so if he jumps into a system with 10 pirates, he will lose 10 points. He can not repair the hull while in space. Bob's goal is to reach system 9999, and he starts at system 0. He can visit any nearby system, but as the cost of space gas has gotten really expensive, he wants to minimize the cost. he must pay 1 unit of fuel times the straight-line distance between systems. (I.e., if bob is at a system with coordinates 0, 0; it costs 10 fuel to move to a system at 0, 10) Bob starts out in system 0. Bob is always in a system: he is never floating in space.

The goal would be to determine the minimum fuel that Bob must expend to go from system 0 to system 9999, while always maintaining at least 1 hull-point. However, you just have to answer these questions:

1. (25 pts) Define how you encode a minimal state to be put in the priority queue for Dijkstra's algorithm or A\*. That is, show me what variables go in the state. Include the metric from problem 3 in the state. Mark or underline the value that will be used to sort the queue. Use as few distinct variables as possible.

2. (25 pts) Given a state, how do we derive every valid neighboring state? Show how every variable is modified from one state to the next. Make sure to distinguish what makes a state valid and what makes a state the destination.

3. (10 pts) Propose a heuristic for A\*. It must be consistent and actually result in a reasonable optimization.

4. (40 pts) Prove your answer for number 3. Include the definition for consistency.
