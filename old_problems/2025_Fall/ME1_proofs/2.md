# ME1: Proofs

1. (25%) Write a function in C: 
```c
#include <stdbool.h>
#include <stddef.h>

bool is_sorted(size_t arr[], size_t n) { ... }
```

Which returns true if and only if the given array is in non-decreasing order.

Examples:
```c
is_sorted((size_t[]){},          0) == true;
is_sorted((size_t[]){5},         1) == true;
is_sorted((size_t[]){1,2,2,3,5}, 5) == true;
is_sorted((size_t[]){1,3,2,4},   4) == false;
```

2. (25%) Prove that it is correct:
    - If you wrote an iterative algorithm, give a correct loop invariant (15%), and verify that it holds after an iteration (10%).
    - If you wrote a recursive algorithm, prove it inductively (10% base case, 15% inductive case). Make sure to handle both $n = 0$ and $n = 1$ base cases.
3. (25%) Determine its big-$\Theta$ running time (using the RAM model). (all or nothing)
4. (25%) Prove that it has that big-$\Theta$
    - For an iterative algorithm, identify the number of loop iterations (15%) and the cost per iteration (10%)
    - For a recursive algorithm, identify its recurrence relation (10%) and either use induction or invoke a lemma that identifies the running time of that recurrence (15%).
