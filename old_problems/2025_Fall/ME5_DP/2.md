# ME 5: DP

You have `n` tasks (at least 1, at most 10000), each with an integer start time and finish time. You’d like to schedule as many non-overlapping tasks as possible on a single processor. You may assume that `start <= finish` for every task. A task can be scheduled at `start, finish` only if no other scheduled task overlaps `start, finish` at all (not even one starting at the same time as the other is finishing)

This time, each task has a `value`, a number from 1 to 1000. Instead of trying to maximize the number of tasks you complete, you are trying to maximize the value.

```c
typedef struct { 
    int start; 
    int finish;
    int value; 
} Task;
```

For every task, `0 <= start <= finish <= 100000`
The tasks are already ordered by finish time, lowest first.

Define the following function in C so that it solves the problem (100 pts):
```c
int max_value(Task tasks[], int n_tasks);
```

Hint: you can scan backwards from task i until you find the first task, j,  that doesn't conflict. Then you can make the choice of whether to take task i or not. Nothing before j will conflict either, so the best score you could get for j will be relevant if you take i.

Your solution must run in $O(n^2)$ time, where $n$ is the number of tasks.
You may not use any functions you did not define yourself.
