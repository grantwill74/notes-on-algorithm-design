# ME 4: A greedy problem (100 pts)

You have `n` tasks (at least 1, at most 1 million), each with an integer start time and finish time. You’d like to schedule as many non-overlapping tasks as possible on a single processor. You may assume that `start <= finish` for every task. A task can be scheduled at `start, finish` only if no other scheduled task overlaps `start, finish` at all (not even one starting at the same time as the other is finishing)

```c
typedef struct { 
    int start; 
    int finish; 
} Task;
```

For every task, `0 <= start <= finish <= 1000000`

Define the following function in C so that it solves the problem (100 pts):
```c
int max_tasks(Task tasks[], int n_tasks);
```

Hint: You are allowed to use `qsort(void* arr, size_t n, size_t elem_size, int (*comparator)(void*, void*)`, and I suggest you do so. Define a comparison function for tasks. No other functions may be used unless you define them yourself (including the comparator).

Hint 2: The goal is to maximize the *number* of tasks, not the total duration scheduled. There is a simple rule you can follow to maximize the number of tasks you schedule. Consider if tasks were ordered by their finish time.

Your answer must be $O(n \lg n)$, where $n$ is the number of tasks (-50 points otherwise).
