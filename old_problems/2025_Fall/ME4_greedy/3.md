# ME 4: A greedy problem (100 pts)

Alice is playing the popular rhythm game Drums Hero on a busted controller. A controller consists of $n$ drums. Because her controller is broken, she can only play one beat at a time. She still wants to maximize her score, by playing as many beats as possible. She receives one point every time she hits a beat. However, if two or more beats happen at the same time, she can only get at most one point.

There are $n$ drums on the controller. $n \gt 0$ There is an array of beats, which look like this:
```c
typedef struct {
    int which_drum;
    int at_time;
} Beat;
```

Every beat `b` obeys these inequalities:
`0 <= n.which_drum < n`,
`0 <= at_time <= 1000000`

Also, there are no instances of beats in which the same drum is playing at the same time. That is, this will never happen: `beats = {..., {d, t}, ... {d, t}, ...}` for any drum `d` or time `t`.

Alice has to hit a beat at the correct time, `at_time`. If two beats have the same `at_time`, Alice can only play one of them. The notes may be arranged in any order in the provided array.

Define the following function in C:
```c
int max_score(Beat* beats, size_t n_beats);
```

You may use `qsort(void* arr, size_t n, size_t elem_size, int (*comparator)(const void*, const void*))`

However, you may not use any other functions unless you define them yourself.

Your solution must be $O(n \lg n)$ (-50 pts if not)
