# ME 3: Complexity Classes

1. (25 pts) Suppose we are performing the sat reduction for a problem. $S_{t, i, a}$ is true and $S_{t, i + 1, b}$ is true. Is is possible for both variables to be true (10 pts)? Explain your answer (15 pts)?

2. (25 pts) Give an example of a reduction where, if we performed it, would *not* prove that P = NP (10 pts). Explain why it would be insufficient (15 pts).

3. (25 pts) Suppose that we're buying a car, and we want to determine if there exists some combination of add-ons that makes it cost exactly $\$40,000$. We write an algorithm that tries every combination of $n$ addons and returns true or false correctly. If this were the only algorithm we were aware of, would we put this problem in P (10 pts)? Explain your answer (15 pts).

4. (25 pts) Suppose we have a connected graph with 4 nodes, and there is a 3-clique present and no 4-clique, and 1 node has a single connected node. What does that say about the size of the largest indset (10 pts) and why (15 pts)? Strong suggestion: draw the graph--it will also count as why.
