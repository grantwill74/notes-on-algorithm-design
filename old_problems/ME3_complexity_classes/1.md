# ME 3: Complexity Classes


1. (25 pts) Suppose we are performing the sat reduction for a problem. $S_{t, i, a}$ is true and $S_{t, i, b}$ is true. Is is possible for both variables to be true (10 pts)? Explain your answer (15 pts)?

2. (25 pts) Give an example of a problem besides "is sorted" and "is matrix product" which, if we reduced the clique problem to it, would prove P = NP. (10 pts). What class is your problem in? (15 pts)

3. (25 pts) Suppose that $A \le_p TSP$. Can we conclude that A is NP complete (5 pts)? Can we conclude that A is NP (5 pts)? For both, explain why or why not (15 pts).

4. (25 pts) Suppose we have a connected graph with 100 nodes, and a minimum VC of 10 nodes. Does that say anything about the largest indset? If so, state its size. If not, explain why not.
