# ME 4: A greedy problem (100 pts)

Bob is playing a role playing game in which you can pick up any amount of an item, even fractional amounts. So if a gold bar weights 100 units, but the player only has 75 carry capacity, they can pick up 0.75 of the gold bar.

You will receive a list of items:
```c
typedef struct {
    char* name;
    double weight;      // weight per unit
    double quantity;    // number of units present
    double value;       // value per unit
} Item;
```

You also have a carry capacity limit `c`. 

Your goal is to determine the maximum value of items that can be carried while being at or below the carry capacity limit. **(100 pts)**

For every item:
`0 <= value <= 1000`
`0 <= quantity <= 1000`
`0 <= weight <= 1000`

Also:
`0 <= c <= 10000`

Define this function:
```c
double max_val(Item* items, size_t n_items, double c);
```

You may use `qsort(void* arr, size_t n, size_t elem_size, int (*comparator)(void*, void*)`
No other functions may be used unless you define them yourself (including the comparator).

Your answer should be $O(n \lg n)$, where $n$ is the number of items (-50 pts otherwise).
