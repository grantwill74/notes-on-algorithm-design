# ME 2: The Master Theorem

Each problem is worth 25 points.

For each recurrence relation:
- If it is a valid recurrence relation for the master method, apply the master method.
  - Show how you compute $A, B, c, k$ (if applicable) (5 points together)
  - $c_\mathrm{crit}$ (5 points).
  - State the case of the master theorem (5 points).
  - Then, write the big-$\Theta$ bound that the master theorem derives and demonstrate the regularity criterion holds if necessary (10 points).
- If it is not a valid recurrence relation for the master method (either failing the regularity criterion or otherwise not a valid shape of recurrence),
  - say so (10 points) and 
  - point out which term, factor, or function causes it to fail and why (15 points).

## Problems
1. $T(n) = 2\cdot T(n / 2) + n(\lg n)^2$
2. $T(n) = 9\cdot T(n / 81) + n^{(1/4)}$ 
3. $T(n) = 81\cdot T(n / 9) + n^3$
4. $T(n) = T(n / 2) + 3^n$
  Hint: This one *does* pass the regularity test.
