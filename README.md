# Welcome
These are my lecture materials for my class
*CS 450: Design and Analysis of Algorithms*,
which I teach at Washington State University, Vancouver campus.

These include the lecture slides that I use, as well as some practice problems,
and even assignments.

If you are a student (mine or otherwise), please use these materials freely to
learn about algorithm design.

These materials are intended to be an open educational resource. If you are a 
teacher, see the section
[Using these materials in your own classes](#using-these-materials-in-your-own-classes)
for information on how to comply with the license.

## Using these materials in your own classes
These materials are licensed under [CC BY-SA 4.0][license deed],
which means that if you
adapt the material: meaning that you remix, transform, or build upon it,
you must mark your adaptations and share the adapted version under the
same license.

This does not mean that merely using one of my slides or 
assignments requires that you must
license your whole presentation under CC BY-SA. Only if you
were improving the presentation itself, such as by fixing errors, or adding
new slides that were meant to go before or after other slides in these decks,
would I expect the specific modifications or improvements to be licensed under
CC BY-SA.

My main intention behind using a share-alike license is to ensure that I can
incorporate error fixes, better explanations, and better diagrams in these
materials, without violating a more restrictive copyright imposed by the
adapter.
